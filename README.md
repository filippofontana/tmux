# Custom `tmux` configuration

> :loudspeaker: Make sure to add it inside you `~/.config` folder.

## How to install plugins?

[`tpm`](https://github.com/tmux-plugins/tpm/tree/master) is already available
here as a git submodule, thus once you open tmux for the first time on a new
machine, you just have to give the following command:

```bash
prefix + shift + i
```

And the specified plugins will be installed.
